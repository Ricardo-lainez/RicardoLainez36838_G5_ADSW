# 1.5 Backlog

| Versión | Contenido |
|---|---|
| G5_Backlog_PlantillaV1.xlsx | Primera versión con los 4 requisitos de la guía |
| G5_Backlog_PlantillaV1.1.xlsx | Versión actual con los 8 requisitos funcionales y los sprints 1 a 8 |

La hoja Backlog tiene una historia de usuario por requisito funcional (tema, como un, necesito, así podré, notas, prioridad y estado). La hoja de sprints tiene cada sprint con su historia y sus tareas (REQ00X-N), el responsable y las horas estimadas. Las tareas describen el trabajo de implementación de cada requisito. El mismo backlog está cargado en Jira: https://36838-g5.atlassian.net/jira/software/projects/SCRUM/boards/1
