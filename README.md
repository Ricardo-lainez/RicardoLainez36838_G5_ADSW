# 36838_G5 - Sistema de Gestión de Pedidos Bocatto

Repositorio del Grupo 5 de Análisis y Diseño de Software (NRC 36838, ESPE). Proyecto: análisis y diseño de un sistema web de gestión de pedidos para el restaurante Bocatto Valley.

## Estructura

| Carpeta | Contenido |
|---|---|
| PROYECTO/1. ELICITACION | ERS, cronograma, matriz IREB, historias de usuario, actas, backlog, pruebas y reporte de errores |
| PROYECTO/2. DISEÑOS | Casos de uso nivel 0, clases de análisis y secuencias, mockups, modelo de datos y piezas visuales |
| PROYECTO/3. CODIGO | Código fuente del sistema (fase de construcción) |
| ANALISIS | Talleres gamificados de análisis con PlantUML |
| DT | Documentación técnica |
| Informe final | Informes y presentaciones del proyecto |
| KANBAN | Evidencias del tablero y los sprints en Jira |

## Planificación actual

Los sprints en Jira trabajan los 4 casos de uso de nivel 0 de la Guía 1 y la Guía 2, para mostrar la trazabilidad desde el requisito hasta su historia de usuario, sus tareas y su pantalla:

| Sprint | Fecha | Requisito |
|---|---|---|
| Sprint 1 | 8 de noviembre | RF002 Tomar pedido en mesa |
| Sprint 2 | 9 de noviembre | RF004 Realizar pedido por QR |
| Sprint 3 | 10 de noviembre | RF005 Gestionar preparación del pedido |
| Sprint 4 | 11 de noviembre al 12 de noviembre (09:00) | RF006 Cobrar pedido en la caja |
