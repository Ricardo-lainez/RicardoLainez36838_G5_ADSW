# 36838_G5 - Sistema de Gestión de Pedidos Bocatto

Repositorio del Grupo 5 de Análisis y Diseño de Software (NRC 36838, ESPE). Proyecto: análisis y diseño de un sistema web de gestión de pedidos para el restaurante Bocatto Valley.

## Estructura

| Carpeta | Contenido |
|---|---|
| 1. ELICITACION | ERS, cronograma, matriz IREB, historias de usuario, actas, backlog, pruebas y reporte de errores |
| 2. DISEÑOS | Casos de uso nivel 0, clases de análisis y secuencias, mockups, modelo de datos y piezas visuales |
| 3. CODIGO | Código fuente del sistema (fase de construcción) |
| ANALISIS | Talleres gamificados de análisis con PlantUML |

| Informe final | Informes y presentaciones del proyecto |
| KANBAN | Evidencias del tablero y los sprints en Jira |
